**What's new in this version**

- **More "Era / when made" options in the intake form.** Step 3 previously only offered vintage eras (1800s through "Before 2007"). It now includes the full set of Etsy options — Made to order, 2020–2026, 2010–2019, 2007–2009, and the older 1910s, 1700s, and Before 1700 — so you can accurately tag newer and handmade items instead of being forced into a vintage bucket.
